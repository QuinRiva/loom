# Querying a plan or recap

When a thread writes a plan or recap and you open it in the right panel, you can ask about it without crowding the thread that wrote it. Select a passage and press **Query** (beside Comment), then type your question. T3 Code opens a query thread: a read-only copy of the writing thread that carries its full reasoning, and answers there with the passage attached. The query goes to the thread that signed the document, whichever thread you open it from; an unsigned document goes to the thread you are viewing it in, and the Query card says which. It can read files and consult the writing thread, but it cannot edit anything; the writing thread stays the document's only author. This needs a thread backed by Pi.

Further questions on the same version of the document land in the same query thread, and each passage you asked about shows a **?** pin that opens its question. Once the writing thread changes the document, the next question starts a fresh query thread. Query threads hang off the writing thread on the workstream graph.

## Promote an answer

When an exchange settles something the document should change, press **Promote to author** under the answer. The query thread writes one comment for the writing thread, anchored to the passage you asked about. You can promote several exchanges from one query thread.

The promoted comment does not reach the writing thread on its own: it waits in that thread's composer, beside your own annotations, until you send it. Edit it or delete it there like any other comment; a deleted promotion does not come back. Once sent, the comment links back to the query thread it came from.
