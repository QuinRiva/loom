## Judgement calls

- **Root isolation:** accepted. `parentThreadId:null` keeps the drafter out of dispatcher selection, parent wake/digest, fan-in, and root-skipping liveness rails; no path found that writes the source transcript.
- **Goal cascade:** acceptable for source `done` or `archived`: an active source keeps the goal open, while archiving the source deliberately makes eventual goal archive consistent. A source **delete** during drafting is a narrow semantic edge: the live drafter prevents the delete-time goal cascade, then drafter settlement archives rather than deletes the goal. Recovery is cheap, so this is not a gate blocker, but an engine-backed lifecycle test should pin the chosen behaviour.
- **Integration depth:** no longer acceptable for settlement. The pure classifier/builder/decider tests all pass yet miss MF-1’s cross-worker race. The rework should add an engine-backed stop-confirmation/restart test rather than another pure test only.
