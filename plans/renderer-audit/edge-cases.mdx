# Renderer audit — deliberate edge cases

**Purpose.** Deliberately-broken blocks split out of `plan.mdx` so the kitchen
sink lints clean. Every block below MUST be flagged by the plan validator
(`node apps/web/scripts/lint-plan.mjs plans/renderer-audit/edge-cases.mdx`),
and in the renderer each degrades to a per-block error card or silent
degradation — never a whole-document crash.
