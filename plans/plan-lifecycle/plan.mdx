<Callout tone="decision" title="As built and done are written on the last PR's branch, before it ships">
  Loom ships only through PRs, so an edit "after the merge" is one more PR per feature, which in practice is skipped and leaves every plan at `approved`. Instead the orchestrator, once the build is final and before it spawns the shipper for the feature's last PR, writes the `## As built` section from the coders' reports and sets `status: done` on that branch; `done` then means "merged with that PR". A near-done round under the intent-first workflow that reopens the build reopens nothing in the plan: the As built section is written once, when the owner has said it works and the last PR is about to ship. A feature with several PRs writes it on the last one.
</Callout>

## 2. Where the supersession trigger lives

A lint sees a file; only the planner knows that the plan it is drafting answers a question an older plan already answered. So the trigger is a before-drafting step in the plan skill (search `plans/`, `recaps/`, `explainers/`, `docs/` with `rg`/`fd` on the area's words, and `mcp__t3-code__thread_search` for the discussion; mark what you replace in the same commit), and the review gate on the plan checks that the planner's report says what it searched and found and that a replaced plan carries its mark. The lint then holds the pair honest. This is a check, not a guarantee, and the brief's "Still unknown" carries it: the first plan written in an area that already has one will show whether the habit fires.

The evidence does not support anything stronger. The recap's survey (`recaps/removed-docs-audit/recap.mdx` §3.2) found every discovery channel ends in a file path and that a marker "is cheap only if it is written at the moment of supersession"; the one supersession in loom's history (`plans/2026-07-16-restart-turn-continuation.md`, gutted to a ten-line stub on 21 Sep) was written by the thread that replaced it, at that moment. A scheduled sweep that guesses supersession from code drift would produce false markers, which is worse than none.
