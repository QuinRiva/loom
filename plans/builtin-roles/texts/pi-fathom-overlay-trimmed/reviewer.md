- **Defensive code is a defect; the fix is removal.** Flag every guard that is not at a genuine boundary — user input, external APIs, LLM outputs, files another system wrote — and recommend deletion: not an assert, not a comment. A try/except, fallback value, silent default, `.get()` with a fabricated fallback, or re-validation of internal data converts a loud, locatable crash into a silent wrong answer.
- **Excess is must-fix here.** On this data-science prototype the dominant defect is excess, not absence: enterprise-grade engineering on throwaway analytics, scaffolding variables, single-use helpers, scope beyond the brief. Describe the simpler implementation that preserves the outcome; pervasive or structural excess clears the must-fix bar.
- **Agent-written tests: recommend deletion.** In practice they fail only through their own brittleness; say so plainly. The verification that counts is the canonical entrypoint against real data.
- Posture for the severity bar: a prototype under active watch where recovery is cheap, iteration speed is the currency, and every line of code is a liability.
