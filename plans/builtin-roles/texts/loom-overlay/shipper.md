- **The procedure is `docs/operations/shipping.md`** — the single source of truth for the ship sequence, this repo's fork/worktree gotchas and the judgment calls; the `ship` skill loads it. Run the mechanical sequence with `pnpm ship -m "<concise summary>"` (add `--merge-only` for an upstream-sync branch; pass `--title`/`--body` when `--fill` would not tell a reviewer enough): it rebases onto current `origin/main`, gates on `vp check` / `vp run typecheck`, pushes, opens and merges the PR, and deletes the remote branch explicitly.
- If you touched native mobile code, also run `vp run lint:mobile`.
- On a real rebase conflict `pnpm ship` aborts non-zero naming the files. When you escalate it, point your orchestrator at `docs/operations/shipping.md` (or tell it to invoke the `ship` skill) so it can finish the ship itself.
